D7 Gaming Engine v0.9.4 — Self-Heal System Doctor

هذا الإصدار يحدث التطبيق نفسه، وليس أداة خارجية منفصلة.

الجديد:
- Self-Heal عند تشغيل D7: يبحث عن بقايا إصدارات D7 القديمة ويعمل لها Backup ثم يزيلها/يعزلها بأمان.
- ترحيل واضح لمهام D7 القديمة وخطط الطاقة القديمة بدل ترك أكثر من محسن يعمل مع Windows في نفس الوقت.
- تصنيف أدق لمصادر PowerShell وCMD عند بدء التشغيل.
- زر تتبع PowerShell/CMD لمدة 90 ثانية يسجل Command Line وParent Process في ملف على سطح المكتب.
- Camo Error Code 22 يظهر كمعلومة (الجهاز Disabled) بدل اعتباره عطلًا مرتفعًا تلقائيًا.
- Event 6008 يُعامل كتاريخ إيقاف غير متوقع، ويرتفع فقط إذا تكرر.
- تتبع أعطال explorer.exe حسب التكرار والحداثة.
- DISM وSFC وCHKDSK لا تعمل عند كل تشغيل؛ فقط عند اختيار «فحص شامل + إصلاح آمن».
- التعديلات العدوانية للأداء مغلقة افتراضيًا: CPU Sets / EcoQoS / Timer 1ms / D7 Power Plan / Priority Boost.
- التحديثات أونلاين تتحقق من SHA-256 قبل التثبيت.

سياسة الأمان:
D7 لا يعدّل ملفات الألعاب أو Anti-Cheat ولا يحذف برامج خارجية بشكل تلقائي. التنظيف التلقائي محصور بالمكونات القديمة المملوكة لـ D7.
