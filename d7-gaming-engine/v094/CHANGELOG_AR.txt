D7 Gaming Engine v0.9.4 — Self-Heal

- تحديث فعلي للتطبيق الأساسي إلى 0.9.4 على قناة Stable.
- إضافة Self-Heal عند التشغيل لترحيل بقايا D7 القديمة قبل أي تشخيص جديد.
- إزالة/عزل مهام D7 القديمة المؤكدة فقط مع Backup مسبق.
- تنظيف خطط D7 القديمة والعودة إلى Windows Balanced.
- إضافة تتبع PowerShell/CMD لمدة 90 ثانية مع Parent Process وCommand Line.
- تحسين تصنيف Camo Code 22 ليظهر كجهاز Disabled بدل خطأ مرتفع تلقائيًا.
- تحسين تقييم Event 6008 وأعطال explorer.exe حسب التكرار والحداثة.
- منع تشغيل DISM/SFC/CHKDSK تلقائيًا عند فتح البرنامج؛ تعمل فقط من زر الإصلاح الشامل.
- إبقاء CPU Sets وEcoQoS وTimer 1ms وخطة D7 وPriority Boost مغلقة افتراضيًا.
- الإبقاء على التحديثات الأونلاين مع تحقق SHA-256 قبل التثبيت.
- لا تعديل لملفات الألعاب أو Anti-Cheat ولا حذف تلقائي لبرامج خارجية.
