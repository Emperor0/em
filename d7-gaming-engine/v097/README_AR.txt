D7 Gaming Engine v0.9.7 — Universal Gaming Mode

شغّل D7 كمسؤول واتركه بالخلفية. النسخة 0.9.7 لم تعد مخصصة لـ Call of Duty؛ تراقب اللعبة الأمامية وتتعرف على مكتبات Steam وXbox وEpic وBattle.net وغيرها.

إذا لم يتعرف D7 على لعبة معيّنة، اضغط «تعلم اللعبة الحالية». سيختفي D7 لمدة 5 ثوانٍ؛ ارجع للعبة، وسيحفظ ملفها في مكتبة D7 المحلية. بعد ذلك سيتعرف عليها تلقائيًا في كل مرة.

عند اكتشاف اللعبة يبدأ Gaming Session مؤقتًا: Windows Game Mode، أولوية AboveNormal للعبة، Windows High Performance إذا كانت الخطة موجودة، خفض أولوية بعض Updaters، وSmart RAM Guard عند ضغط 16GB RAM. عند إغلاق اللعبة تتم استعادة خطة الطاقة والأولويات وإعداد Game Mode السابق.

زر NVIDIA Center يكشف NVIDIA App وnvidia-smi ويعرض حالة GPU/Driver وإعدادات NVIDIA الآمنة المقترحة ويفتح NVIDIA App. D7 لا يستخدم طرقًا سرية أو غير موثقة لتعديل قاعدة NVIDIA Driver Profiles في هذه النسخة.

زر «إعدادات اللعبة الحالية» يعطي Presets مناسبة للتختيم والجودة وBalanced والتنافسي على RTX 2060 SUPER / 1080p / 165Hz.

لا تستخدم هذه النسخة CPU affinity/Sets أو EcoQoS أو Timer 1ms أو BCD/HPET أو RAM purge أو خطط D7 مخصصة، ولا تعدّل ملفات الألعاب أو Anti-Cheat.
