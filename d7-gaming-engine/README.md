# D7 Gaming Engine

قناة البناء والتحديث الرسمية لتطبيق D7 Gaming Engine على Windows.

- التطبيق يبنى كملف `D7_Gaming_Engine.exe` ‏64-bit وبصلاحية المسؤول عند الحاجة.
- الواجهة عربية RTL بهوية D7 الحديثة: Obsidian Black + Electric Lime + Cyan.
- قناة التحديث المستقرة: `d7-gaming-engine/stable/latest.json`.
- كل حزمة تحديث تتحقق من SHA-256 قبل التثبيت.
- لا يوجد DLL injection ولا كتابة في ذاكرة اللعبة ولا تجاوز لـ Anti-Cheat.
- ملفات الحالة المحلية والسجلات وGame DNA لا ترفع إلى GitHub.
